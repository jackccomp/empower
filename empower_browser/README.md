# Empower Browser (experimental)

Runs a visible Chromium browser on Home Assistant OS, including ARM64 Home Assistant Blue / ODROID-N2. Open its interface through Home Assistant, sign in to Empower yourself, and read the loaded electricity dashboard. There is no Mac dependency.

This is an unverified browser compatibility test until Empower accepts a login on your device. Site protection may still block Chromium. It does not bypass site protection or automate challenges.

See DOCS.md for installation and operation.
